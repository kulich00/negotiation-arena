# ArenaLM

ArenaLM v1 — небольшая собственная модель классификации переговорных реплик.
Она определяет одно из 11 намерений игрока, возвращает уверенность и извлекает
числовое предложение. Модель работает локально без внешнего API.

Первая версия использует символьные n-граммы и мультиномиальную языковую модель.
Такой вариант подходит текущему небольшому корпусу, быстро обучается на CPU и не
требует сторонних Python-библиотек. HTTP-контракт отделён от реализации, поэтому
в следующей версии статистическую модель можно заменить нейросетью PyTorch.

## Данные

- `../corpus/seed-v1.jsonl` — диалоги, созданные игровым движком;
- `data/bootstrap-intents.jsonl` — дополнительные размеченные формулировки;
- `data/eval-intents.jsonl` — отдельный небольшой набор для регрессии;
- `model/arena-intents-v1.json` — обученный артефакт.

Runtime-корпус можно добавить несколькими флагами `--corpus`. Неполные записи
автоматически пропускаются.

## Обучение и оценка

Из корня проекта:

```powershell
python -m ml.train `
  --corpus corpus/seed-v1.jsonl `
  --output ml/model/arena-intents-v1.json `
  --version arena-intents-v1

python -m ml.evaluate --minimum-accuracy 0.85
python -m unittest ml.tests.test_model -v
```

Eval-набор содержит 33 близких к обучающему домену примера. Его результат
показывает отсутствие известных регрессий, но не заменяет проверку на большой
выборке реальных сообщений.

## HTTP API

Сервис запускается контейнером `model` на порту `8090`.

- `GET /health` — версия и готовность модели;
- `POST /v1/interpret` — классификация объекта `InterpretationRequest` backend.

Пример ответа:

```json
{
  "intent": "ask_interest",
  "proposalValue": 0,
  "alternativeId": "",
  "relevant": true,
  "confidence": 0.97,
  "modelVersion": "arena-intents-v1"
}
```

Backend сначала применяет строгие локальные правила к очевидным действиям,
затем обращается к ArenaLM. При низкой уверенности, ошибке или недоступности
сервиса сохраняется существующий fallback. ArenaLM не изменяет очки, состояние
переговоров и результат сессии.
